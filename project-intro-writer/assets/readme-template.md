## 模板使用说明（生成正文时删除本节）

- 全文目标 **80~120 行**；正文**不放"编制说明"块**，末行用引用块一句指向配套文件。
- 正文**不出现任何来源标记**：不写"（来源：《xxx》）"、不放演示链接、不提文档名、不写"演示环境实测"。
- 核心能力**只描述能力本体**，严禁逐一罗列模块、页面、字段、接口、KPI 明细。
- 成果章节**只写结果与价值**，过程性内容下沉到配套文件。
- 禁用渲染词（"赋能""抓手""极大提升""告别痛点"）与判断性措辞（"必须""硬性义务""自选动作"）。
- 详细撰写细则见技能内 `references/writing-guide.md`。
